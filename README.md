## 关于我

我关注 AI 产品与 Agent，喜欢从真实任务出发理解产品如何被使用、背后的工作流程如何运转，以及哪些问题值得继续探索。

我也把分析、写作和学习中反复使用的方法整理成 Skills，再通过文章与交互作品分享实践。对我来说，研究、工具和表达是一条相互连接的路径：

**观察与体验 → 整理方法 → 制作与分享**

- **研究产品**：关注用户任务、产品体验，以及 Agent 的职责、工具与人机分工。
- **沉淀方法**：把可复用的分析、写作和知识整理流程写成 Skills。
- **创作与表达**：通过中文文章和交互式网页，记录思考、呈现想法。

项目的具体实现、适用范围与使用方式，请查看各仓库说明。
