## 全部项目

### AI Skills

#### [ai-product-teardown · AI 产品拆解](https://github.com/DarkHummingbird/ai-product-teardown)

从真实任务和体验进入，展开商业、用户流程、技术、模型、资产与壁垒分析。

- 覆盖网页、手机 App、桌面客户端、插件，以及仅依据用户材料的分析。
- 拆解 Agent 职责、上下文、工具与人机分工，整理模型用途与成本。
- 输出 Markdown / HTML 或飞书文档，包含模型表格与可编辑架构图。

`AI 产品` `Agent` `产品研究` `架构分析` `Skill`

#### [wechat-writing · 公众号写作](https://github.com/DarkHummingbird/wechat-writing)

面向 AI、科技与 AI 产品的中文公众号写作工作流。

- 从观点、标题、热点或链接开始，分阶段完成选题、切入角度、大纲与成稿。
- 按材料组合可扩展写法，支持已有稿件编辑。
- 查找公告、产品资料等真实素材与配图；发布由作者自己完成。

`公众号` `AI 写作` `内容创作` `编辑工作流` `Skill`

#### [course-notes-skill · 课程笔记整理](https://github.com/DarkHummingbird/course-notes-skill)

把课堂录音、转写和课件，转化为可以独立阅读的中文学习笔记。

- 按概念与方法组织内容，让例子回到对应知识点。
- 结合课件截图与裁剪，保留图表和方法细节。
- 配套 Python 脚本，检查笔记结构、表达规则与链接。

`知识管理` `学习笔记` `Python` `文档处理` `Skill`
